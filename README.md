# MyFood

## 项目宗旨

MyFood 用来记录“吃过什么”，帮助我们在有限预算下，尽可能接触更多不同的食物。

人的记忆不可靠。日常吃饭经常重复，吃过的食物、食材和口味很容易被遗忘；等到想回顾或寻找新的尝试时，又很难知道自己已经吃过什么、还没有吃过什么。

因此，这个项目不以餐厅、城市、金额或复杂分类为核心，而以一次具体的食物体验为核心：

- 记录一道食物由哪些食材组成
- 记录其中明显的香料和调味料
- 记录食物的口味
- 记录个人偏好：偏好吃或偏难吃
- 逐步形成属于自己的“吃过什么”数据库

## 记录原则

- 菜名知道就填，不知道可以不填
- 食材是核心信息，可以填写一个或多个
- 香料只记录辣椒、洋葱、蒜等明显可识别的配料
- 调味料可以不填，只有在具有区分价值时才记录
- 口味使用酸、甜、苦、辣、咸
- 不强迫记录日期、餐厅、城市、金额和菜系
- 不要求用户先理解复杂分类，再开始记录

## 产品方向

MyFood 最终希望回答三个问题：

1. 我吃过哪些食物？
2. 哪些食材和口味我还没有体验过？
3. 下一次怎么用有限的钱，获得新的食物体验？

## 数据结构

一条记录包含：

```text
菜名
食材[]
口味[]
偏好
```

## 技术说明

项目采用 Web 页面记录数据，Web 服务与 PostgreSQL 数据库分别运行在独立 Docker 容器中。记录数据保存到 PostgreSQL，不依赖浏览器本地存储。
